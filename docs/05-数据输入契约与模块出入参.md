# 数据输入契约与模块出入参

> 本文由 `scripts/gen-io-doc.mjs` 根据代码契约（`src/core/input-contract.ts` 的 `INPUT_CONTRACT`、`src/workspace/module-catalog.ts`、`src/workspace/module-io.ts`）**自动生成**，请勿手改；修改契约后执行 `npm run docs:io`，`npm run check` 会校验本文与代码一致。

## 一、数据流总览

```
来源端（公开接口 / 授权行情）
  └─ 接入方整理为 5 份落盘输入 + manifest（本节契约）
       └─ validateDatasetInput(data, { modules | preset })   ← 注入前校验（组件注入后也会自动校验并派发 data-validate）
            └─ deriveDataset()  运行时派生：chips / intradayMulti / trades / depthFull / depthScenarios / historicalIntraday
                 └─ <stock-workspace>.data  → 各模块只读消费
```

- 接入方**只需提供** `manifest` 与按启用模块所需的落盘输入；派生数据集由组件计算，**不要自行提供**（注入通道 `historicalIntraday` / `prevIntraday` 除外，见各模块「可选输入」）。
- 单位约定：价格 = 元；成交量 = **股**（公开接口多返回「手」，需 × 100）；竞价匹配量 = **手**（与公开接口一致）；成交额 = 元；百分比 = % 数值；`tradeDate` / `time` 为市场本地字符串，`timestamp` 为 UTC 毫秒。
- `validateDatasetInput()` 返回 `{ ok, required, errors, warnings }`：`errors` 为结构性问题（缺输入 / 缺字段 / 顺序错 / OHLC 越界 / 手股单位错配 / 委托引用断裂 / 越涨跌停），会导致图表口径错误；`warnings` 为可容忍偏差（派生层会锚定修正）。

## 二、落盘输入契约

| 输入 | 名称 | 形态 | 可得性 | 来源端获取途径 |
|---|---|---|---|---|
| `manifest` | 标的与交易日元信息 | 对象 | 必填元信息 | 交易所 / 行情接口的证券基本资料与当日行情头（代码、名称、昨收、开收盘）；流通股本取自上市公司定期报告或行情软件 F10 |
| `bars` | 日 K 线 | Bar[]（按 tradeDate 升序） | 公开日频（免费可得） | 东方财富 push2his kline（11 列）/ 新浪 / 腾讯日线等公开日频接口；交易所日频行情表 |
| `intraday` | 当日分时（分钟线） | IntradayPoint[]（按 time 升序） | 公开分时（当日 / 近几日） | 腾讯 minute/query、东方财富 trends2 等公开分时接口（返回累计量额，需差分为每分钟增量）；历史分时一般只回溯近几日 |
| `auction` | 集合竞价过程 | AuctionPoint[]（开盘 + 收盘两段） | 即时行情需实时留存（历史不可回溯） | 即时行情在竞价阶段给出参考价 / 匹配量 / 未匹配量，需在 9:15–9:25、14:57–15:00 逐点采集留存；历史过程无法回溯（同花顺等按 9 秒一点展示） |
| `depth` | 盘口快照（十档） | DepthBookSnapshot[]（取首个快照） | Level-2 授权行情 | 五档为公开 L1 即时行情；十档属 Level-2 增值行情，需向上证所信息网络 / 深证信息申请展示许可 |
| `orders` | 逐笔委托事件流 | OrderRecord[]（按 time 非递减） | Level-2 授权行情 | 上交所 Level-2 逐笔合并流（新增 A / 撤单 D / 成交 T）、深交所逐笔委托 + 逐笔明细；需 Level-2 授权 |

### manifest · 标的与交易日元信息

| 字段 | 类型 | 单位 | 必填 | 说明 |
|---|---|---|---|---|
| `symbol` | string | — | ✅ | 证券代码.交易所 |
| `name` | string | — | ✅ | 证券简称 |
| `tradeDate` | string | — | ✅ | 当日交易日 YYYY-MM-DD |
| `preClose` | number | CNY | ✅ | 昨收价 |
| `open` | number | CNY | 可选 | 当日开盘价（缺省取当日日 K） |
| `close` | number | CNY | 可选 | 当日收盘价 / 最新价（缺省取当日日 K） |
| `limitRate` | number | — | 可选 | 涨跌幅限制比例（缺省按代码 / 名称识别板块：主板 0.1、创业 / 科创 0.2、ST 0.05、北交所 0.3） |
| `floatShares` | number | share | 可选 | 流通股本；bars 未提供 turnoverRate 时据此计算换手率（筹码分布需要） |
| `adjust` | string | — | 可选 | 复权方式 'qfq' \| 'hfq' \| 'none' |
| `session` | array | — | 可选 | 连续竞价时段 [{open, close}] |
| `files` | object | — | 可选 | loadDataset 用：输入键 → 文件名（setDataset 直接注入时可省略） |
| `tradeDates` | array | — | 可选 | 多日分时用的近 N 个交易日 |
| `preCloseByDate` | object | — | 可选 | 多日分时用的逐日昨收 |

市面口径与约束：

- symbol 采用「代码.交易所」形式（如 600519.SH / 000001.SZ / 688xxx.SH / 8xxxxx.BJ）
- limitRate 按板块：主板 0.1、创业板 / 科创板 0.2、主板 ST 0.05、北交所 0.3
- preClose / open / close 必须与当日日 K 一致；换手率 = 成交量 ÷ 流通股本
- session 为连续竞价时段，A 股为 09:30–11:30、13:00–15:00

### bars · 日 K 线

| 字段 | 类型 | 单位 | 必填 | 说明 |
|---|---|---|---|---|
| `tradeDate` | string | — | ✅ | 交易日 YYYY-MM-DD |
| `open` | number | CNY | ✅ | 开盘价 |
| `high` | number | CNY | ✅ | 最高价 |
| `low` | number | CNY | ✅ | 最低价 |
| `close` | number | CNY | ✅ | 收盘价 |
| `volume` | number | share | ✅ | 成交量 |
| `amount` | number | CNY | ✅ | 成交额 |
| `preClose` | number | CNY | 可选 | 昨收（缺省取上一根 close，首根取开盘价） |
| `timestamp` | number | UTC ms | 可选 | 交易日 00:00 UTC（缺省由 tradeDate 计算） |
| `turnoverRate` | number | percent | 可选 | 换手率（缺省 = volume ÷ manifest.floatShares） |
| `pctChg` | number | percent | 可选 | 涨跌幅（缺省由 preClose 计算） |
| `amplitude` | number | percent | 可选 | 振幅（缺省由 preClose 计算） |
| `change` | number | CNY | 可选 | 涨跌额（缺省由 preClose 计算） |

市面口径与约束：

- 量能在公开接口里多为「手」，落盘须 × 100 转为股
- low ≤ min(open, close) ≤ max(open, close) ≤ high；tradeDate 严格递增
- 同一复权口径下 preClose 与上一根 close 相等；振幅 = (high − low) ÷ preClose

### intraday · 当日分时（分钟线）

| 字段 | 类型 | 单位 | 必填 | 说明 |
|---|---|---|---|---|
| `time` | string | HH:MM | ✅ | 分钟标签 |
| `price` | number | CNY | ✅ | 该分钟收盘价 / 最新价 |
| `volume` | number | share | ✅ | 该分钟成交量（增量） |
| `amount` | number | CNY | ✅ | 该分钟成交额（增量） |
| `tradeDate` | string | — | 可选 | 所属交易日（缺省取 manifest.tradeDate） |

市面口径与约束：

- 时间轴 09:30–11:30、13:00–15:00（241 或 242 点，依供应商是否单列 13:00）
- 首个分钟点 09:30 含开盘集合竞价成交（腾讯 / 东财口径），逐笔中的 09:25 竞价成交即取该点量额
- 可选盘后固定价段 15:01–15:30（不参与日 K 量能、不画在分时主图）
- 连续竞价段成交量合计应等于当日日 K 成交量；分时价应落在日 K 高低之间

### auction · 集合竞价过程

| 字段 | 类型 | 单位 | 必填 | 说明 |
|---|---|---|---|---|
| `time` | string | HH:MM:SS | ✅ | 时点 |
| `phase` | string | — | ✅ | 'open' 开盘竞价 \| 'close' 收盘竞价 |
| `virtualPrice` | number | CNY | ✅ | 虚拟参考价 |
| `matchedQty` | number | lot | ✅ | 虚拟匹配量 |
| `unmatchedQty` | number | lot | ✅ | 虚拟未匹配量 |
| `unmatchedSide` | number | — | 可选 | 未匹配方向：1 买方堆积 / 2 卖方堆积 / 0 无 |
| `timestamp` | number | UTC ms | 可选 | 时点时间戳（缺省由 tradeDate + time 计算） |

市面口径与约束：

- 开盘 09:15–09:25（09:20 后不可撤单），收盘 14:57–15:00（不可撤单）
- matchedQty / unmatchedQty 以「手」为单位（与公开接口一致）
- 09:25 末点 virtualPrice = 当日开盘价、matchedQty × 100 = 首个分钟点成交量；15:00 末点 = 收盘价

### depth · 盘口快照（十档）

| 字段 | 类型 | 单位 | 必填 | 说明 |
|---|---|---|---|---|
| `bids` | array | CNY / share | ✅ | 买盘 [{price, volume}]，≤ 10 档 |
| `asks` | array | CNY / share | ✅ | 卖盘 [{price, volume}]，≤ 10 档 |
| `timestamp` | number | UTC ms | 可选 | 快照时间戳 |

市面口径与约束：

- 买盘价格降序、卖盘价格升序，买一 < 卖一，价格为 0.01 元整数倍
- 挂单量以「股」落盘（市面盘口多显示「手」，差 100 倍）；每档笔数由 orders 聚合，可不提供

### orders · 逐笔委托事件流

| 字段 | 类型 | 单位 | 必填 | 说明 |
|---|---|---|---|---|
| `ordId` | string | — | ✅ | 委托号 |
| `time` | string | HH:MM:SS | ✅ | 事件时间 |
| `price` | number | CNY | ✅ | 委托 / 成交价 |
| `volume` | number | share | ✅ | 委托 / 成交 / 撤单量 |
| `side` | string | — | ✅ | 'B' 买 \| 'S' 卖 |
| `action` | string | — | ✅ | 'NEW' \| 'CANCEL' \| 'FILL' |
| `origOrdId` | string | — | 可选 | CANCEL / FILL 指向的原委托号（NEW 为 null） |

市面口径与约束：

- action：NEW 新增委托、CANCEL 撤单、FILL 成交；CANCEL / FILL 用 origOrdId 指向原 NEW
- 买入申报为 100 股整数倍；价格在涨跌停区间内且为 0.01 元整数倍
- 09:20–09:25 与 14:57–15:00 不可撤单；11:30–13:00 午休无委托
